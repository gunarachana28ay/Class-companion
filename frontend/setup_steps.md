# How to Run

1. **Ensure Node JS and NPM are installed. Node >= v16.20.2 and NPM >= 8.19.4** 

2. **Navigate to the frontend folder**: ```cd .\frontend\```

3. **Install all packages/dependencies**: ```npm install```

4. **Create a new .env file and copy the content of .env.example file into this new .env file. Make sure to change the values appropriately. For example if you are running the server on port 8001, change the value of port to 8001.**

5. **Start the server in development mode**: ```npm start```
